# 열차 고장 유사 사례 검색

운행장애 기록을 대상으로 고장 증상을 검색하고, 유사 사례 최대 5건의 관리번호, 발생 일시, 발생 장소를 표시하는 로컬 웹앱입니다. 사례를 펼치면 시발역, 종착역, 차량 수, 차량 도입일과 운행장애 개요 원문을 볼 수 있습니다. 상세 정보의 빈값은 ‘미기록’으로 표시합니다.

## 실행

Python 3.10 이상이 필요합니다. VS Code에서 프로젝트 폴더를 열고 PowerShell 터미널에서 실행합니다. 설치할 Python 패키지는 없습니다.

```powershell
python app.py --csv "$env:USERPROFILE\Downloads\FRACAS_20220830_utf8.csv"
```

브라우저에서 `http://127.0.0.1:8000`을 열고 고장 증상을 입력합니다. 종료하려면 터미널에서 Ctrl+C를 누릅니다. 포트가 사용 중이면 명령 끝에 `--port 8001`을 추가하고 터미널에 나온 주소를 사용합니다.

## 검색 방식

UTF-8 CSV에서 `FRACAS관리번호`, `고장발생일자`, `고장발생시각`, `발생장소명`, `운행장애개요내용`, `시발역명`, `종착역명`, `열차차량수`, `차량도입일자`를 읽습니다. 단어와 연속 두 글자의 겹침을 비교하고, 여러 기록에 흔하게 나오는 표현의 가중치를 낮춥니다. 발생장소명이 비어 있으면 ‘장소 미기록’으로 표시합니다. 원본 CSV는 제자리에서 읽으며 프로젝트에 복사할 필요가 없습니다.
